Girl Hub category sealing update

- Closed categories remain clickable and their page still opens.
- The category page is shown in grayscale with a yellow/black caution strip containing the custom message (for example SOON).
- Products belonging to a closed category are filtered out of offers, recommendations, search, and other product grids outside their own category page.
- The category message editor is now a multi-line field; promo code entry in the dashboard is larger and easier to read.

Local preview: run the v11 folder using Live Server. Open the storefront and admin dashboard using the same origin and port. These edits are local-browser behavior until the site is deployed; shared/live sync still depends on the configured backend.
