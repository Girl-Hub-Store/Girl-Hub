# Girl Hub V18 Fixes

- Closed category tiles now block category links and direct `category.html?cat=...` access redirects to the parent section.
- Hero slide text/button are positioned per slide without overlap.
- Image cropping opens in a dedicated full-screen modal cropper instead of inside the product card.
- Products support multiple images; the first uploaded image is the main image and product detail shows a thumbnail gallery.
- Offers slider now forces product-card navigation on click when the gesture was not a drag.
- Social links from the storefront header were seeded into Dashboard settings (Instagram, TikTok, WhatsApp; Facebook remains editable).
- Existing remote Supabase data remains the source of truth.
